## Security

- Retain gossiped bodies while their parent context becomes available.
  Release the supplier verification gate between bounded retries.

- Check V5+ block authorizing-data commitments before transaction verification and retry alternate-body failures without invalidating the honest block hash
  ([#1038](https://github.com/zakura-core/zakura/pull/1038)).

- Preserve header-only commitment failures as neutral body-verification outcomes;
  replacing a delivered body cannot repair invalid header bytes or parent-history
  commitments. Authorizing-data mismatches remain attributable to the body supplier.
