  `zakura_rpc::getblocktemplate` target with why the request woke, how long
  it waited and how long the template took to build. Silence it with
  `zakura_rpc::getblocktemplate=warn`
  ([#2045](https://github.com/zakura-core/zakura/pull/2045)).
