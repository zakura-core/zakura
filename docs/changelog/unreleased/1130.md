## Fixed

- Preserve valid blocks waiting for their parent when an overlapping submission
  has altered transaction data under the same header. Retained bodies keep their
  own mining receipt priority, and a rejected variant no longer rejects children
  while another retained body can commit. If all variants fail, consensus
  rejection still wakes waiting callers even when another body was mismatched.
  Writer capacity failures also release queued descendants so they can be retried.
  Native body sync retries duplicates that are still awaiting validation instead
  of treating them as verified
  ([#1130](https://github.com/zakura-core/zakura/pull/1130)).
