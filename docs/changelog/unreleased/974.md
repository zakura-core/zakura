## Security

- Reject nested collection counts that cannot fit in complete Block and headers
  messages before reserving memory, and keep capping the reservation itself at
  a fixed number of elements, so a count the input could hold still cannot size
  an allocation in proportion to the message. Use the configured network's
  header sizes so Regtest's smaller encoding does not loosen Mainnet or Testnet
  checks ([#974](https://github.com/zakura-core/zakura/pull/974)).
