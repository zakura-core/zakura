## Changed

- Start up to 50 legacy peer connection attempts concurrently and immediately
  refill the window when an attempt completes. Configure a non-zero
  `network.initial_peer_dial_concurrency` to change the window; existing total
  peer and per-IP limits still apply
  ([#2327](https://github.com/zakura-core/zakura/pull/2327)).

## Fixed

- Allow legacy dials to known peers while a getaddr crawl awaits network
  responses, without changing the crawl cooldown or steady-state dial pacing
  ([#2327](https://github.com/zakura-core/zakura/pull/2327)).
- Cancel spawned legacy handshakes when their caller is dropped, releasing
  streams and connection reservations promptly
  ([#2327](https://github.com/zakura-core/zakura/pull/2327)).
