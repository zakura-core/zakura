## Fixed

- Prevented header sync from admitting VCT auxiliary input that durable state
  already retains or has rejected or disputed. Each repair now claims the exact
  durable episode. Header sync rotates suppliers after peer-attributed
  failures. It does not reuse a supplier or a supplier's retained rooted slot
  until the episode changes. It waits when no eligible supplier remains. An
  auxiliary-capacity refusal waits until state reports available capacity
  ([#847](https://github.com/zakura-core/zakura/pull/847)).
