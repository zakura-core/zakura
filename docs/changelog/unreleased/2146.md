## Changed

- Finalized transaction bodies now move from RocksDB into append-only static files in the state directory, on a background thread, in batches of at least 50 blocks. Existing databases migrate in place under state format v31, a major version that reuses the v30 cache, so older releases can't open the upgraded cache
  ([#2146](https://github.com/zakura-core/zakura/pull/2146)).
- Stop and restart read-only RPC secondaries around `zakurad rollback-state`, because rollback deletes and shortens transaction static files in place
  ([#2146](https://github.com/zakura-core/zakura/pull/2146)).
