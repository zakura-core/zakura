## Changed

- Bounded native P2P raw frames and queued frames without another owner across
  each connection and the node. A connection whose local consumers lag behind
  its budget now pauses that stream's reader or sender instead of retaining more
  memory, and each stream keeps room for one frame. The node budgets hold every
  connection's budget, so one peer's traffic cannot pause another. Connection
  teardown now waits, for a bounded time, for its aborted stream workers before
  returning its connection slot. A subscription's terminal outcome now queues
  behind prior data without waiting for queue space
  ([#1620](https://github.com/zakura-core/zakura/pull/1620)).
- Counted native P2P frames that the node has read but still keeps against the
  peer's QUIC receive window, so a peer can't send more while the node holds
  its earlier frames. `quic.receive_window_bytes` may now be smaller than
  `quic.stream_receive_window_bytes`
  ([#1620](https://github.com/zakura-core/zakura/pull/1620)).
