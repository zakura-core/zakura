## Added

- Added the opt-in binary `/submittrustedblock` endpoint, which follows the
  primary listener's `enable_cookie_auth` setting.
  It begins relay before local validation, then returns the normal validation
  and commit result. Committed broadcasts reuse active early announcements to
  avoid duplicate inventories on healthy peer connections. Operators should validate the exact final block bytes on
  a trusted full node first: receivers can ban a relay that sends an invalid
  block. Invalid submissions do not disable later trusted submissions
  ([#2534](https://github.com/zakura-core/zakura/pull/2534)).
