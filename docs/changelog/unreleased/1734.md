This PR adds a required `name` field to `zakura-network`'s public
`MessageRule` struct and the `LayoutError::DuplicateName` and
`LayoutError::MalformedName` variants. `Stream::validate_layout` now rejects a
layout in which two rows share a name, or a row name holds anything other than
lowercase ASCII letters, digits, and hyphens. Code that builds a `MessageRule`
must set the new field. Nodes behave as before, so the change has no
operator-visible effect.
