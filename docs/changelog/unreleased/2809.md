## Fixed

- With BPv1 enabled, native block sync no longer downloads a second copy of a near-tip block that BPv1 is about to deliver. BPv1 claims the body before headerchain sees the header, and native block sync briefly reserves a body whose header arrives first. Header sync no longer fetches a near-tip header from a BPv1 peer whose `HeaderMeta` carries it ([#2809](https://github.com/zakura-core/zakura/pull/2809)).
