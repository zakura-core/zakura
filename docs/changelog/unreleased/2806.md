## Changed

- A v2 node now has a discovery dial target of 23 ordinary outbound
  connections, bootstrap peers included. Discovery stops starting ordinary
  dials once the node has 23, instead of dialing until it holds 83 of the
  Mainnet default of 92 connections. Bootstrap peer redials and, on the Dual
  stack, legacy upgrade dials don't check the target, so outbound connections
  can still go above 23 within the 92. The node still accepts up to 69 inbound
  connections within the same 92 total. Reachable nodes used to dial each
  other up to 83 and leave about 9 slots each for nodes whose discovery record
  carries no address, such as one on the default wildcard listener without
  `network.external_addr`, which can only dial. Now most of their 69 inbound
  slots stay free for those nodes. In a network of about 25 to 83 reachable
  nodes with few dial-only nodes, a reachable node can end up with fewer peers
  than before ([#2806](https://github.com/zakura-core/zakura/pull/2806)).
