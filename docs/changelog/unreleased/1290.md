This PR clarifies the allocation-size test helper and updates its callers without
changing node behavior or production deserialization limits. The `proptest-impl`
public helper is renamed to `serialized_sizes_at_allocation_limit`, returns only
the two serialized sizes, and no longer requires `Clone`. This feature-gated Rust
API break is covered by the pending `zakura-chain` 10.0.0 major version.
