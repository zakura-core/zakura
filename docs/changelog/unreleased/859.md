## Added

- Add halving-preserving reissuance behind the disabled-by-default `nu7`
  feature. The bonus is `ceil(parent_deficit * 4126 / 10^10)` from the
  configured reissuance start height. The default start maps the February
  2031 crossing rule through ZIP 218's halving clock
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
- Store the signed issuance deficit alongside chain value pools. The balance
  starts at zero at NU7 and excludes historical funds pending policy guidance.
  Both state commit paths reject negative balances from the reissuance start.
  Database format 29.0.0 backfills the unseeded balance and propagates migration
  failures ([#859](https://github.com/zakura-core/zakura/pull/859)).

## Changed

- Read the actual parent's deficit for verification, subsidy RPCs, and block
  templates. Wait for pending parent commits within verification timeouts.
  Return an error when the required parent balance is missing or negative
  ([#859](https://github.com/zakura-core/zakura/pull/859)).

## Fixed

- Applied deferred funding streams inside slow start when replaying block info
  during the format 27 upgrade and during offline rollback, matching block
  commits on configured networks
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
