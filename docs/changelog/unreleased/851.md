## Added

- Added ZIP 218 "25-second Block Target Spacing" rules at NU7. From the
  configured NU7 activation height onwards, the rules apply a 25-second block
  target spacing, a 102-block difficulty averaging window, and a block subsidy
  divided by the spacing ratio. Networks without an NU7 activation height follow
  today's consensus ([#851](https://github.com/zakura-core/zakura/pull/851)).
- Retained ZIP 218's maximum difficulty context in every build. Startup extends
  older, narrower contexts before validation
  ([#851](https://github.com/zakura-core/zakura/pull/851)).

## Changed

- Scaled non-consensus timing to the target spacing at each height, so it
  follows the 25-second spacing after NU7: the Testnet `getblocktemplate`
  minimum-difficulty heuristic, the `getnetworksolps` default window, the
  legacy syncer lookahead (3 times larger, as ZIP 218 recommends), the inbound
  gossip lookahead window, the legacy peer near-tip threshold, the sync stall
  warning, and the checkpoint update hint. Networks without an NU7 activation
  height behave as before
  ([#851](https://github.com/zakura-core/zakura/pull/851)).
- Raised the header-chain disk format to 5. Downgrading to an earlier release
  after this upgrade needs a header-chain resync. The earlier release now stops
  with an unsupported header-chain disk format error instead of a row limit
  error ([#851](https://github.com/zakura-core/zakura/pull/851)).

## Fixed

- Fixed the Testnet `getblocktemplate` heuristic to read the minimum-difficulty
  gap at the candidate block's height, as the consensus rule does
  ([#851](https://github.com/zakura-core/zakura/pull/851)).
- Fixed Regtest to derive its first halving height from its target spacings.
  With NU7 active, funding stream recipients now rotate from the height where
  the subsidy halves ([#851](https://github.com/zakura-core/zakura/pull/851)).
- Fixed startup to report a full state rolled back below the persisted header
  finality before it extends the difficulty context
  ([#851](https://github.com/zakura-core/zakura/pull/851)).
