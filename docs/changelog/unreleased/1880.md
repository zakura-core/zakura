## Added

- On Linux, the `p2p` trace table records the kernel's TCP state when a block
  body write returns, and a `body_acked` row once the peer acknowledged the
  whole body, with the time from write start to acknowledgement, the
  retransmits during the upload, and the delivery rate. A `body_ack_timeout`
  row records uploads that were not acknowledged within 30 seconds or whose
  connection closed first. Other platforms record no TCP columns.

  ([#1880](https://github.com/zakura-core/zakura/pull/1880))
