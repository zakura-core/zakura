## Changed

- On a new tip the node now builds the `getblocktemplate` template without
  waiting for a request, so a request that arrives after the block is
  answered from it instead of building its own. A request without a long
  poll ID takes that template only when it is the one the node would build
  for it in that second; otherwise it builds its own, as before
  ([#2352](https://github.com/zakura-core/zakura/pull/2352)).
