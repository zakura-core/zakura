## Security

- Capped the QUIC connections a native node holds, handshakes and closed
  connections still draining included, so a peer that gets rejected and
  reconnects can't pile up buffers outside `peer_memory_budget_bytes`. A
  closed connection now frees its slot within 3 s, however long the peer's
  `max_ack_delay`. The budget funds the admitted connections plus
  `max_pending_handshakes` of headroom, so the default `max_connections`
  drops from 102 to 70, and a larger configured value is lowered at startup
  ([#1508](https://github.com/zakura-core/zakura/pull/1508)).
