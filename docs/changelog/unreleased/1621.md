This PR moves discovery's shared state into a pure `DiscoveryState` and bounds
its verifier, result, book, and snapshot owners. A verified record keeps its
slot until installation. A `Hello` install drops hints of disconnected peers.
One peer's cached live summaries stop at the per-response limit. Wire formats,
configuration, and metrics stay the same. Debug logs gain the book's exact
record changes. The machine tests add no operator-facing behavior.
