## Changed

- `zakurad` builds its bundled RocksDB without the features it doesn't use,
  such as transactions, backups, and SST file ingestion, again, with
  `zakura-rocksdb` 0.24.3. This leaves out about 540 KB of code and shortens
  clean builds. RocksDB's behavior for Zakura and the on-disk database format
  are unchanged. The release build no longer fails to link with GCC 16, which
  is why the trimmed build was turned off in 1.7.0
  ([#1652](https://github.com/zakura-core/zakura/pull/1652)).
