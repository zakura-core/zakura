## Fixed

- Relayed blocks of up to `advert_window_small_size_bytes` (100 KiB by default) are now
  advertised to every peer at once. Previously, peers that already had the block held an
  advert window entry for 3 s each, which delayed the rest of the fan-out by up to 12 s
  ([#2076](https://github.com/zakura-core/zakura/pull/2076)).
