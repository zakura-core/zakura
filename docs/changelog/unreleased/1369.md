## Security

- Native legacy transaction requests now give up on a peer 8 seconds after
  sending it the request, or 13 seconds after queueing it including time
  spent behind other requests to that peer, and try the next one. A silent
  or trickling peer can no longer use up a mempool download's deadline. A
  request cancelled while waiting for its turn no longer delays later requests
  ([#1369](https://github.com/zakura-core/zakura/pull/1369)).
