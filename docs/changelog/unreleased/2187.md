## Added

- A test network that forks the public Testnet's history can now activate the post-quantum
  transparent output rules. A configured Testnet may ask for them when it is nobody else's
  chain: its own name and network magic, its own initial peers, and a real activation height
  ([#2187](https://github.com/zakura-core/zakura/pull/2187)).
- `getnetworkparameters` reports the chain's name, its post-quantum activation height and its
  NU7 height, so an operator can confirm which rules a running node is applying
  ([#2187](https://github.com/zakura-core/zakura/pull/2187)).
- `deploy/custom-testnet` builds and resets such a network: it refreshes a preserved archive
  against the public Testnet behind two agreeing public observations, mints a run identity with
  a non-public network magic, restores the seed into two validators, and begins mining once
  both agree with it ([#2187](https://github.com/zakura-core/zakura/pull/2187)).

## Changed

- `mining.internal_miner_threads` now takes effect. The internal miner solved Equihash on one
  thread whatever the setting said, because cancelling work when the best tip changed had to
  come first. The count is capped by the machine's CPUs and by the 256 distinct nonce ranges a
  solver can claim, and still defaults to one thread
  ([#2187](https://github.com/zakura-core/zakura/pull/2187)).
