## Added

- Added the `network.compact_block_relay` option, off by default, for early
  block relay as defined in the draft Compact Block Relay ZIP
  (zcash/zips#1429). When both legacy peers set service bit 16
  (`NODE_COMPACT_BLOCKS`), Zakura relays a fully verified NU5 or later tip
  block before its contextual commit finishes, and does not score a negotiated
  peer for a block that fails after its header and commitments check out
  ([#773](https://github.com/zakura-core/zakura/pull/773)).
