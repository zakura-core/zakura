This PR finishes the simulator build of the internal `zakura-rt` crate for
the header-sync path, behind `--cfg zakura_sim`: stable task labels, the
missing preemption points, a sim `StreamMap` and `Weak`, and a tighter
import check. It also fixes a borrow panic in the internal, unpublished
`zakura-scheduler`. The production build behaves as before, so it has no
operator-visible effect.
