## Changed

- Replaced the experimental one-time WOTS spend with post-quantum transparent
  accounts on regtest: one fixed address whose signing key changes on every
  spend, checked by consensus rules over the whole transaction rather than by a
  script opcode. The mempool accepts the account input forms and zero-value
  control outputs, and the regtest demo covers chained spends, retries within a
  step and forged spends. Zakura Common is repinned to the commit that adds the
  account rules
  ([#1774](https://github.com/zakura-core/zakura/pull/1774)).
