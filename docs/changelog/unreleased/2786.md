## Changed

- A v2 node now uses its Zakura bootstrap peers only to find its first peers. It dials them while it has fewer than two outbound peers of its own, and once four other hosts have stayed connected for a minute it closes every connection it opened to them. The bootstrap peers' inbound slots no longer fill once the v2 network outgrows them. A small network whose nodes are all bootstrap peers keeps them connected as before ([#2786](https://github.com/zakura-core/zakura/pull/2786)).
