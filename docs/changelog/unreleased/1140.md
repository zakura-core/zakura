This PR adds crate-private session tools with no production caller yet, and
tests. It also bumps `zakura-network` to 9.0.0 for the message regulation
stack's public transport API changes and `zakura-rpc` to 12.0.0 because its
public API uses network traits. The dependency requirements are updated
together. These library version changes have no operator-visible effect.
