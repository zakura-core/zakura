## Changed

- The header chain now retains 138 headers of difficulty context below the
  finalized height instead of 112, ready for NU7.1's 128-block averaging
  window. Startup migrates the header-chain database to disk format 6 and
  backfills the extra rows from full state. Older releases refuse a format 6
  database, so rolling back after this release needs a resync
  ([#2777](https://github.com/zakura-core/zakura/pull/2777)).
