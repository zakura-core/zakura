## Fixed

- A node that commits two of its own blocks at one height while it has no peer announces
  both to the first peer that connects, instead of only the later one, and a block this
  node submitted that the chain has not committed yet is no longer kept for replay to
  Zakura peers that connect later
  ([#1976](https://github.com/zakura-core/zakura/pull/1976)).

## Changed

- Each peer-to-peer protocol sends at most 16 block announcements at once; further blocks
  wait for one to finish ([#1976](https://github.com/zakura-core/zakura/pull/1976)).
