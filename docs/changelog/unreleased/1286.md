<!-- changelog: none -->

This PR removes redundant tests and assertions, unused fixtures, disabled test
code, and unused Rust state-query and test-support APIs. It has no operator-visible
node behavior, RPC, configuration, or database-format effect.

The Rust API removals can affect crate consumers, including optional-feature
consumers. They are enumerated in the PR description. `zakura-test` is bumped to
3.0.0; existing pending major bumps in `zakura-chain`, `zakura-network`, and
`zakura-state` cover their additional API removals.
