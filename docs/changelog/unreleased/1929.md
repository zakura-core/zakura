## Fixed

- Legacy sync now checks a downloaded block's proof of work and parent before
  verifying it. A block whose parent the node can't build on, and that isn't
  still downloading after passing the same check, is dropped right away
  instead of waiting in the verifier. A real block dropped this way is found
  again by a later tip refresh or sync round. Dropped and rejected blocks no
  longer count as sync progress, so a round that verifies nothing restarts
  after the usual stall timeout
  ([#1929](https://github.com/zakura-core/zakura/pull/1929)).
