## Changed

- `getblocktemplate` long polls that ask for the same work now share one
  template: the first builds it and the others take it, instead of each
  choosing transactions and building its own. Miners sharing a template get
  the same transactions and work ID. Requests without a long poll ID still
  get a template of their own
  ([#2345](https://github.com/zakura-core/zakura/pull/2345)).
- Reusing a shared template renews or restores its work-ID registration so
  compact submissions can reconstruct work after cache expiry or eviction.
