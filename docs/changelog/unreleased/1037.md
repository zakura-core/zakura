## Security

- Enforce an absolute verified-progress deadline during active retries.
  Wake discovery tracking at feedback and cooldown deadlines.

- Credit block-discovery peers only after verified progress, bound discovery feedback, and preserve useful candidates across concurrent commits
  ([#1037](https://github.com/zakura-core/zakura/pull/1037)).

## Changed

- Bump `zakura-network` to 11.0.0 for the discovery feedback API.
  `Response::BlockHashes` now has named hash and feedback fields, and `Response`
  no longer implements `UnwindSafe` or `RefUnwindSafe`
  ([#1037](https://github.com/zakura-core/zakura/pull/1037)).
