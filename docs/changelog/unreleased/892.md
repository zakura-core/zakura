## Security

- Bound native `GetBlocks` serving work per peer and across the node, while
  retaining one response producer per session through state completion and
  transport writes. Delay locally saturated requests without penalizing the
  requesting peer or adding serving byte budgets. Pause stream reads at admission
  and let QUIC apply backpressure while response writes continue independently. Retain response terminators
  through temporary output queue pressure, with a local session deadline.
  Reject response byte limits below the maximum block size so available blocks
  can be served
  ([#892](https://github.com/zakura-core/zakura/pull/892)).
