## Added

- Configured Testnets accept `inherit_activation_heights = true` in their
  `network = { ... }` parameters. The configured `activation_heights` then
  overlay the public Testnet heights instead of replacing every height above
  genesis, so a fork can set only `NU7`. The default and configs that list every
  height are unchanged, and Regtest rejects the key
  ([#1097](https://github.com/zakura-core/zakura/pull/1097)).
