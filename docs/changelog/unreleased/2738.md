## Fixed

- TEX addresses with a Bech32 checksum are now rejected; ZIP 320 requires
  Bech32m ([#2738](https://github.com/zakura-core/zakura/pull/2738)).
- Converting an `i64` above `Height::MAX` to a block height now fails, and
  adding or subtracting a height difference that overflows `i64` returns
  `None` instead of panicking or wrapping
  ([#2738](https://github.com/zakura-core/zakura/pull/2738)).
