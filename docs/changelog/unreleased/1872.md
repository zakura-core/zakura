## Added

- `getmininginfo` reports the network `difficulty`, as zcashd does
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).

## Changed

- The RPC server accepts versionless and JSON-RPC 1.0 batches, and answers each
  member in its own format, so pool software such as s-nomp passes its startup
  checks ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
- `submitblock` accepts any JSON value as its ignored second argument
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
