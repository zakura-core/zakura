## Changed

- Finalized transaction bodies now move from RocksDB into append-only static files in the state directory, in batches of 50 blocks near the tip and 1,000 while syncing. Existing databases migrate in place under state format v31, a major version that reuses the v30 cache, so older releases can't open the upgraded cache
  ([#2146](https://github.com/zakura-core/zakura/pull/2146)).
