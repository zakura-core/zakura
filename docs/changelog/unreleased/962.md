## Added

- Added opt-in spentness construction. Checkpoint sync skips the UTXO writes, reads, and deletes of outputs that die before the terminal checkpoint, and keeps exact balances, address indexes, and value pools. It works in archive and pruned modes, and gates only UTXO-set reads until the terminal checkpoint. The mode defaults to `off` and requires a reviewed artifact commitment ([#962](https://github.com/zakura-core/zakura/pull/962)).

## Changed

- Bump `zakura-state` and `zakura-consensus` to 9.0.0 for breaking public API changes.

- Retry pre-state artifact acquisition across peer cohorts for up to one hour.
  Auto mode then falls back to ordinary sync; Require mode reports failure.

- Moved state to database format 30 to isolate incomplete spentness construction from older binaries. The upgrade reuses ordinary format-29 state, and format-28 state through consecutive reusable versions ([#962](https://github.com/zakura-core/zakura/pull/962)).
