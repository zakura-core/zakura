## Changed

- Native Zakura streams for block sync and legacy gossip now reject an
  undeclared message type, any frame flag, or an out-of-bounds payload length
  from the frame header, before reading the payload. Discovery accepts `Peers`
  and `Services` only in answer to its own request, and it answers peer
  requests without dropping replies when its send queue is full. Legacy gossip
  checks each list count against the payload length before allocating the list
  ([#860](https://github.com/zakura-core/zakura/pull/860)).
