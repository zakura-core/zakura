This PR makes `zakura-network`'s library build with `--cfg zakura_sim` by
naming runtime types through the internal `zakura-rt` crate and adding
`zakura_rt::task::try_spawn`. It also adds a time-taking variant of the
internal `zakura-header-chain` trust-anchor audit. The production build
behaves as before, so it has no operator-visible effect.
