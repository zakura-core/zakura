## Added

- Added `state.static_files_dir`, which puts finalized transaction static files under `<static_files_dir>/vN/<network>` instead of inside the state directory, so they can live on another disk. Zakura still refuses a `static_files` link. Snapshots keep the default layout, so after restoring one on a node with this setting, move its `state/vN/<network>/static_files` contents into the configured directory
  ([#2353](https://github.com/zakura-core/zakura/pull/2353)).
