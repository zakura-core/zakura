## Changed

- A v2 node now stops starting discovery dials once it has 23 ordinary
  outbound connections, bootstrap peers included, instead of filling 83 of
  the Mainnet default of 92 connections with them. It still accepts inbound
  connections up to the same total, so a reachable node keeps its peer count,
  and more of those peers are nodes that dialed it. Before, reachable nodes
  filled each other's slots and left none for nodes whose discovery record
  carries no address, such as one on the default wildcard listener without
  `network.external_addr`, which can only dial
  ([#2806](https://github.com/zakura-core/zakura/pull/2806)).
