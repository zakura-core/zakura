This PR moves the block-sync reactor's query, completion, view, admission,
and floor-watchdog decisions into a pure state that the existing reactor task
calls. A forced needed-block query now keeps its force across a full action
channel or a failure. A closed action channel ends query dispatch instead of
arming a retry timer. These internal changes have no operator- or
crate-consumer-visible effect. The PR also retains the query and reactor
machine drivers from #1677 and #1683 and adds targeted reactor transition traces.
