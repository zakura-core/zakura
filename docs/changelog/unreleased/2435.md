## Removed

- Removed public functions with no callers: `zakura-chain`'s
  `Transaction::has_transparent_inputs_or_outputs` and
  `transparent::OutputIndex::{as_usize, as_u64}`, and `zakura-state`'s
  `read::find::tip_hash`
  ([#2435](https://github.com/zakura-core/zakura/pull/2435)).

## Changed

- Test-only public APIs are now available only with the `proptest-impl`
  feature: `zakura-chain`'s `work::difficulty::INVALID_COMPACT_DIFFICULTY`,
  `transparent::OrderedUtxo::from_utxo`,
  `ConfiguredFundingStreamRecipient::new_for`,
  `LockTime::max_lock_time_timestamp` and
  `Transaction::sprout_joinsplit_pub_key`, and `zakura-consensus`'s
  `CheckpointVerifier::from_list`. `zakura-consensus`'s hidden
  `clear_shielded_verification_caches` now needs the `internal-bench` feature
  ([#2435](https://github.com/zakura-core/zakura/pull/2435)).
- Public APIs used only by tests within their own crate are no longer
  compiled into library builds: `zakura-chain`'s
  `ConfiguredFundingStreams::into_funding_streams_unchecked`,
  `sapling::Output::into_v4`, `sapling::OutputInTransactionV4::into_output`,
  `HistoryTree::try_extend`, `Network::sapling_activation_height` and
  `ValueBalance::money_reserve`, and `zakura-network`'s
  `spawn_zakura_endpoint`, `Config::update_peer_cache`,
  `InventoryChange::new_missing` and `ConnectedAddr::new_{outbound,inbound}_proxy`
  ([#2435](https://github.com/zakura-core/zakura/pull/2435)).
