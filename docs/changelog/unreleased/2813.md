## Added

- Added ZIP 248 v7 transaction validation from NU7.1, including v7 coinbase
  transactions that state their block's height, subsidy, and lockbox deposit.
  NU7.1 has no Mainnet or Testnet activation height and release builds still
  reject NU7.1 blocks, so this only applies to test builds on Regtest or
  configured Testnets that set an NU7.1 height
  ([#2813](https://github.com/zakura-core/zakura/pull/2813)).
