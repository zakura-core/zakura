This PR splits the block-sync peer routine into a pure `PeerState` and a
`PeerIO` that holds its runtime handles, moves request write handles out of the
download window, extracts the serve response bound and commitment margin, and
adds machine tests for them. Request issuance, response handling, deadlines,
fault attribution, and settlement are unchanged, so it has no operator- or
crate-consumer-visible effect.
