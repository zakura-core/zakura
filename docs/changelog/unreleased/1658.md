This PR makes `zakura-network`'s library build with `--cfg zakura_sim` by
naming runtime types through the internal `zakura-rt` crate, adding
`zakura_rt::task::try_spawn`, and passing a `Clock` to the internal
`zakura-header-chain` startup audit. The production build behaves as before,
so it has no operator-visible effect.
