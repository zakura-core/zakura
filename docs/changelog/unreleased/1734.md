This PR adds a required `name` field to `zakura-network`'s public
`MessageRule` struct and a `LayoutError::DuplicateName` variant.
`Stream::validate_layout` now rejects a layout in which two rows share a name.
Code that builds a `MessageRule` must set the new field. Nodes behave as
before, so the change has no operator-visible effect.
