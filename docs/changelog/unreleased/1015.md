## Changed

- Preserve the previous major-format database when starting a build with a new format. Set `state.reuse_previous_database = true` to permit supported upgrades to move it instead. Switching back after reuse can require a backup restore or a resync ([#1015](https://github.com/zakura-core/zakura/pull/1015)).
- Keep non-finalized block backups in separate directories for each database major format. Nodes fetch missing recent blocks from peers instead of restoring legacy unversioned backups ([#1015](https://github.com/zakura-core/zakura/pull/1015)).

## Fixed

- Reject databases with a newer recorded major format before opening them, including read-only opens. Automatic cleanup retains the immediately preceding major-format database for switching back ([#1015](https://github.com/zakura-core/zakura/pull/1015)).
