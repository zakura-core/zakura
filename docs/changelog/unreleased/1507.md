## Security

- Capped native P2P connections by a new `[network.zakura]
  peer_memory_budget_bytes` setting, 8 GiB by default. Each connection's QUIC
  windows and datagram queue can hold 80 MiB that the node can't reclaim, so
  256 connections could hold 20 GiB. The default `max_connections` drops from
  256 to 102. A larger configured value is lowered at startup with a warning,
  and startup fails when the budget admits fewer than 16 connections, or fewer
  than a smaller `max_connections`
  ([#1507](https://github.com/zakura-core/zakura/pull/1507)).
