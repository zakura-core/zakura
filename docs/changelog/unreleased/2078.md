## Changed

- Raised the default `advert_window_min` and `advert_window_max` from 32 and 64
  to 400, so every block is advertised to up to 400 peers at once. Relayed blocks
  previously reached the last peers 9 to 12 s late in 3 s waves. Config files
  that set these values keep them, and a file that sets only
  `advert_window_max` below 400 must now also set `advert_window_min`
  ([#2078](https://github.com/zakura-core/zakura/pull/2078)).
