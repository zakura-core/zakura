## Security

- Ban authenticated Zakura peers that supply malformed block or transaction
  encodings, and apply the existing transaction ban policy to native suppliers.
  Attribute downloaded transactions to the actual supplier, including fallback
  peers. Bans reject reconnects from the same identity until FIFO eviction from
  the bounded in-memory history or node restart
  ([#2085](https://github.com/zakura-core/zakura/pull/2085)).
