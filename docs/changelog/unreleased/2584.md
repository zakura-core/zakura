## Fixed

- With `network.block_source_score.enabled`, Zakura remembers a legacy peer’s
  measured block delivery score and whether it missed an announced block across
  reconnects. Each is retained for up to 30 minutes. A peer passed over for a
  recent miss can regain preference by delivering a requested block
  ([#2584](https://github.com/zakura-core/zakura/pull/2584)).
