## Changed

- A v2 node whose discovery record carries no address, such as one on the
  default wildcard listener without `network.external_addr`, now dials up to
  23 discovered peers instead of 83 at the default 92 connections. No peer can
  dial such a node, so each of its dials took an inbound slot on a reachable
  peer. Inbound connections don't count against the new limit, and nodes that
  advertise an address are unchanged
  ([#2806](https://github.com/zakura-core/zakura/pull/2806)).
