## Security

- Native legacy requests now try the next peer alongside one that has not
  started answering within 3 seconds, so a silent peer can no longer use up a
  block, transaction, or tip request's deadline, while a slow peer can still
  answer. A request cancelled while waiting for its turn no longer delays
  later requests ([#1369](https://github.com/zakura-core/zakura/pull/1369)).
