## Added

- `getmininginfo` reports the network `difficulty`
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).

## Changed

- The RPC server accepts homogeneous versionless and JSON-RPC 1.0 batches and
  answers in the caller's format
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
- `submitblock` accepts any JSON value as its ignored second argument
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
- Bump `zakura-rpc` to 14.0.0-rc0 for Rust API changes: the mining information
  response adds a difficulty getter and constructor argument and drops `Eq`;
  HTTP compatibility middleware constructors take a response size limit
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).

## Fixed

- Before the first block, RPC methods that default difficulty report `1.0`
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
- Legacy conversion preserves raw parameters and explicit null IDs, converts
  batch-level errors, and enforces the response limit after conversion
  ([#1872](https://github.com/zakura-core/zakura/pull/1872)).
