## Added

- Four CSV trace tables record block lifecycle boundaries for orphan-rate
  analysis, selectable with `[network.zakura] trace_tables`:
  - `p2p` records legacy wire send attempts, completed writes, decoded
    receives, the connection ID and direction, and every block hash in an
    inventory batch.
  - `p2p_request` records peer selection, including the selected connection's
    active request and queue depth, and the connection queueing, write, and
    completion of each request.
  - `block_gossip` records block broadcast upload-slot waits, inventory
    queueing and writes, and why each slot was released.
  - `block_verify` records download, verification, and commit timing for
    gossiped and synced blocks.

  ([#1877](https://github.com/zakura-core/zakura/pull/1877))
