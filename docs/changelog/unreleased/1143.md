## Fixed

- After NU7, the ZIP 214 Revision 2 funding streams (Zcash Community Grants and the
  lockbox) now end at the third halving as moved by ZIP 218, not the pre-ZIP-218 height.
  Funding stream recipient addresses now rotate once every three address-change intervals
  after NU7, so the existing addresses cover the longer streams. No public network sets an
  NU7 height yet, so behavior does not change today
  ([#1143](https://github.com/zakura-core/zakura/pull/1143)).
