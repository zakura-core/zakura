## Removed

- Removed the optional `sentry` crate feature and Sentry reporting from
  `zakurad`, and the `zakura-watchdog` Sentry sidecar. `zakurad` now always
  installs its color-eyre panic report hook
  ([#1318](https://github.com/zakura-core/zakura/pull/1318)).

## Fixed

- Compatibility deployment suppression also pauses queued Slack deliveries
  without dropping them. SSH probe output collection and cleanup share the
  command deadline, including when detached children hold stdout open
  ([#1318](https://github.com/zakura-core/zakura/pull/1318)).

- Monitoring deployment uses an independently verified SSH host key, checks
  both active release SHAs before retiring the Rust watchdog, and reports
  service failures. Rollback retries preserve the original release target and
  can resume incomplete Rust watchdog restoration
  ([#1318](https://github.com/zakura-core/zakura/pull/1318)).

## Changed

- `deploy/zcashd-compat/sync-check.sh` now wraps the Python `zakura-compat-check`
  checker, and the fleet watchdog posts zcashd-compat failures and recoveries
  to Slack. The checker's default height drift is 10 blocks, as in the deployed
  watchdog; set `HEIGHT_MAX_DRIFT=30` for the NU7 spacing
  ([#1318](https://github.com/zakura-core/zakura/pull/1318)).
