## Fixed

- The mempool no longer drops and re-verifies every transaction when two or
  more blocks arrive between its chain tip checks. It now removes only the
  transactions those blocks mined or conflict with, so block templates keep
  the rest of the mempool
  ([#1715](https://github.com/zakura-core/zakura/pull/1715)).

## Changed

- `zakura_state::TipAction::Grow` has a new `skipped_blocks` field listing
  blocks added between the previous tip and the new tip, oldest first. Code
  that destructures `Grow` must handle the new field
  ([#1715](https://github.com/zakura-core/zakura/pull/1715)).
