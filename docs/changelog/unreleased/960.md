## Changed

- The mempool no longer bans peers that relay invalid transactions. Many
  transaction verification failures depend on the node's own view of the chain,
  such as lock times checked against a lagging tip, so bans cut off honest peers
  indefinitely. Instead, the mempool ignores transactions from that IP address
  for 10 minutes, doubling for repeated failures up to 2 hours, and the peer
  stays connected. Lock time failures start no cooldown. Block verification
  failures still ban peers
  ([#960](https://github.com/zakura-core/zakura/pull/960)).
