## Changed

- The `zcash.net.peers.connected` and `zcash.net.peers.obsolete` metrics no
  longer carry a `remote_version` label. They gain a `user_agent` label that
  names the peer's client family: `Zakura`, `Zebra`, `MagicBean` or `other`.
  `zcash.net.peers.connected` now counts only peers that complete the
  handshake ([#2585](https://github.com/zakura-core/zakura/pull/2585)).

## Security

- Fixed unbounded Prometheus series growth from legacy peers. A peer could
  create a new series with each protocol version it offered, and a connected
  peer could create one with each distinct malformed message, because the
  closing `zakura.net.connection.state` label quoted the error message
  ([#2585](https://github.com/zakura-core/zakura/pull/2585)).
