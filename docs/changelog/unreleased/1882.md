## Changed

- Bounded legacy TCP and compatibility ingress. Each outbound compatibility
  exchange now holds funding from its own partition through decode, and TCP
  decoders reserve at most 64 KiB before a message body arrives. Decoded inbound
  gossip and requests share a byte budget, so a saturated budget refuses work
  instead of retaining more memory. Header responses now keep their read admission
  through the send, and a separate charge covers their copied bytes. Decoded TCP
  `block` and `tx` messages share a node-wide byte budget. A response to this node's
  request never refuses, and a saturated budget drops an unsolicited transaction.
  The TCP decoder now continues past ignored Bloom and unknown commands to the next
  message, so that message no longer waits for more bytes from the peer. An inbound request stream now reserves its
  response's output before the service runs, so a peer that stops reading holds
  further requests before they execute
  ([#1882](https://github.com/zakura-core/zakura/pull/1882)).
