## Fixed

- Start legacy connections to cached peers without waiting for seed DNS. Seeds
  that resolve during startup take alternate startup dials. A live cached peer
  lets startup finish even if the cache is smaller than the target and DNS is
  unavailable. Without a live connection, an undersized cache still waits for
  seed fallback; seeds resolving after startup go to peer discovery
  ([#2328](https://github.com/zakura-core/zakura/pull/2328)).
