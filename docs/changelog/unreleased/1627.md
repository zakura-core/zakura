This PR only restructures the header-sync peer routine's internals. The
publisher's, subscriber's, and session reader's policy moves into pure state
types under their existing locks, and publisher jobs gain exact keys.
The publisher's slots, capacity signals, and frames stay in its runtime owner,
which names them to the pure state by exact identity.
The publication ledger returns facts, and its runtime owner emits the same
metrics, logs, and transition events from them.
The simulator gains a `header/publisher-policy` machine harness over the existing
publisher model, which bumps the simulator's trace format to 22.
Behavior, wire formats, configuration, metrics, and traces do not change, so
it has no operator- or crate-consumer-visible effect.
