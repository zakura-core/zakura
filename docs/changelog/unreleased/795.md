## Added

- Added NuTachyon network-upgrade and V7 transaction support, including ZIP-233
  amounts, Tachyon bundle serialization, consensus validation, chain state,
  verbose RPC output, and block-template aggregation
  ([#795](https://github.com/zakura-core/zakura/pull/795)).
- Added `gettachyonblock` in NuTachyon builds to serve ordered public chain
  inputs for wallets and services updating spendability proofs
  ([#795](https://github.com/zakura-core/zakura/pull/795)).

## Fixed

- Fixed block-template generation stopping at NuTachyon activation by reserving
  V7 coinbase resources, including the ZIP-233 amount and empty Tachyon bundle
  ([#795](https://github.com/zakura-core/zakura/pull/795)).
- Fixed `gettachyonblock` returning block hashes and transaction IDs as byte
  arrays instead of display-order hex strings, allowing wallets to initialize
  and synchronize using the documented response format
  ([#795](https://github.com/zakura-core/zakura/pull/795)).
