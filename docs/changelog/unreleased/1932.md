This PR adds simulator and fuzz test support: machine-trace records and
shrinking, a shared machine adapter, a campaign lock probe fix, a boundary-read
guard, and an empty `qa/fuzz/p2p` package. It also adds per-connection reactor
receive budgets derived from message tables, which nothing uses yet. `zakura-rt`
changes only its simulator build, and `zakura-network` gains a feature no
production build enables. Neither changes `zakurad`.
