## Security

- Negotiate bounded GetBlocks serving, response authorization, frame limits, and
  Status cadence on native block-sync version 3. Keep version 2 behavior for old
  peers. Exclude local read pauses from ending deadlines and treat unexpected
  header hashes as local incompatibility without peer penalties. Track serving
  completion per session to reduce waiting-request bookkeeping. Version 3 peers
  are advertised at most 2,816 in-flight requests by default, derived from a
  512 MiB budget for queued serving bookkeeping across every inbound and
  outbound session slot.
