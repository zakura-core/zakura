## Changed

- A v2 node whose discovery record carries no address, such as one on the
  default wildcard listener without `network.external_addr`, now stops
  starting discovery dials once it has 23 ordinary outbound connections,
  bootstrap peers included, instead of 83 at the Mainnet default of 92
  connections. Peers can't learn a dial address from such a record, so each
  of its dials took an inbound slot on a reachable peer. Inbound connections
  don't count against the new limit, and nodes that advertise an address are
  unchanged ([#2806](https://github.com/zakura-core/zakura/pull/2806)).
