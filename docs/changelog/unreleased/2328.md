## Fixed

- Start legacy connections to cached peers without waiting for seed DNS. Seeds
  that resolve during startup take alternate startup dials. A live cached peer
  lets startup finish even if the cache is smaller than the target and DNS is
  unavailable. Without a live connection, an undersized cache still waits for
  seed fallback. When startup has not tried a seed-derived peer, late seeds get
  a finite connection opportunity within existing outbound headroom, independent
  of peer gossip. DNS failure does not reserve that headroom indefinitely.
  Failed startup dials are marked failed in the address book, so the crawler
  does not retry them before untried peers. The peer cache keeps only peers that
  responded to this node in the last 3 hours, not gossiped addresses. A cached
  peer whose startup dial fails stays eligible for later retries
  ([#2328](https://github.com/zakura-core/zakura/pull/2328)).
