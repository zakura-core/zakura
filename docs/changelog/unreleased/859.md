## Added

- ZIP 234 halving-preserving reissuance, behind the off-by-default `zip234`
  build feature. ZIP 234 starts at NU7. The per-block reissuance fraction scales
  when ZIP 218 enables 25-second blocks
  ([#859](https://github.com/zakura-core/zakura/pull/859)).

## Changed

- `block_subsidy` takes the money reserve after the parent block, which ZIP 234
  needs. Callers that cannot reach a ZIP 234 height pass `None`, and get a
  `MissingMoneyReserve` error rather than a wrong subsidy if that ever changes
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
- `ReadRequest::BlockInfo` searches every non-finalized chain instead of only the
  best chain, so a block verifier can look up a parent on a fork. Height queries
  still resolve on the best chain first
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
- `Request::AwaitBlockInfo` waits for a block to commit before it returns the
  block's chain value pools. ZIP 234 verification uses this request for parent
  blocks that are still being verified
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
