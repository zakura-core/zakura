This PR makes the header-sync v9 codec, `ZakuraEndpoint::new` and
`ZakuraEndpoint::dial` public in `zakura-network`, and adds a public `id()`
to `zakura-quic`'s streams, so simulator peers can build v9 messages and a
simulated node can dial. That widens both crates' public API, but only for
simulator test infrastructure, and production behavior doesn't change.
