## Removed

- Removed the optional `flamegraph` Cargo feature and built-in tracing-span
  flamegraph output. Remove `flamegraph` from build feature lists and
  `tracing.flamegraph` from configuration files; the removed setting is now
  rejected as an unknown field. Use the external CPU profiling workflow for
  sampled CPU flamegraphs
  ([#1306](https://github.com/zakura-core/zakura/pull/1306)).
