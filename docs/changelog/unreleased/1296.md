## Security

- Bound native QUIC connection state through handshake failures, transport
  drain, and retained stream cleanup. Preserve outbound capacity when inbound
  connections or control handshakes fill their share. Keep failed and closed
  inbound attempts charged to their source IP while their state may remain, so
  one IP cannot fill the inbound share. Allow a bounded reconnect attempt from
  an IP at its limit so the peer can clear a stale connection
  ([#1296](https://github.com/zakura-core/zakura/pull/1296)).
