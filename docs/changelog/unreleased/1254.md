This PR moves the workspace onto the stable `bip32` 0.6, `secp256k1` 0.33 and
`zcash_script` 0.6 releases (with `libzcash_script` 0.2), patches the Zakura
2.2 crates to a revision built on that stack, and relaxes the exact Zakura
crate requirements to caret requirements. It adapts tests and local testnet
key generation to the new `secp256k1` API and has no operator-visible effect
on validation, serialization or configuration.
