## Added

- Added mempool metrics that read the same in both pools:
  `mempool.peer_penalty.total` counts bans, cooldowns and disconnects caused
  by transactions, `mempool.full_queue.per_peer.total` gains a `source` label,
  the pool core exports how many transactions it pools and how many a reset
  took out that are not back yet,
  and `mempool.implementation` shows which pool the node resolved to
  ([#2506](https://github.com/zakura-core/zakura/pull/2506)).
- Added `zakura.p2p.tx_relay.registered`, which says whether the node
  registered `tx-relay`
  ([#2506](https://github.com/zakura-core/zakura/pull/2506)).
