This PR moved the workspace's RocksDB dependency from `zakura-rocksdb` 0.24.0
to 0.24.2 and turned its `full` feature off. #1583 turned `full` back on:
without it, `zakura-librocksdb-sys` 0.17.5 still compiles code that calls into
the sources it skips, and `zakurad` fails to link with GCC 16. With `full` on,
0.24.2 compiles the same RocksDB as 0.24.0, so operators see no change. The
version change is recorded in #1558's fragment.
