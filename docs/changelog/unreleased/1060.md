## Changed

- Set NU7 activation heights: Mainnet 3,543,000 and Testnet 4,386,000. Both are
  estimates for 2026-11-05 and 2026-10-06 from the
  [NU7 timeline](https://forum.zcashcommunity.com/t/nu7-timeline/57655); the
  Mainnet height is final on 2026-10-20, and
  [#1059](https://github.com/zakura-core/zakura/issues/1059) tracks the final
  heights ([#1060](https://github.com/zakura-core/zakura/pull/1060)).
- Every build rejects version 4 transactions from the NU7 activation height
  (ZIP 2003) ([#1060](https://github.com/zakura-core/zakura/pull/1060)).
- Zakura advertises network protocol version 170190, the NU7 version from
  ZIP 204 ([#1060](https://github.com/zakura-core/zakura/pull/1060)).
- On Mainnet and the default Testnet, a header-chain database written under
  different network parameters is audited and rebound at startup instead of
  being rejected ([#1060](https://github.com/zakura-core/zakura/pull/1060)).

## Removed

- Removed the `nu7` build feature from `zakura-consensus` and `zakurad`. NU7
  rules activate by height in every build
  ([#1060](https://github.com/zakura-core/zakura/pull/1060)).
