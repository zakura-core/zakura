This change adds a generator lane to the mutation loop: an in-process
`zakura-sim generate` command, its use in `cargo xtask planted loop`, a
rerun of each kill's input on the unpatched build, recorded triage, and a
droplet timer that runs the loop and diffs its reports. It lets the
simulator's generators draw hostile block-sync and discovery scenarios,
and closes mut-7's simulator gaps. The timer's routine also fuzzes each
suite target in a resumable campaign store, archives the failures, and
reports which suite rows it didn't run. The production change is a
behavior-preserving refactor of inbound message admission plus hooks that
compile only in test and simulator builds. The simulator and xtask aren't
published, and release builds behave as before.
