## Removed

- Removed the standalone `zakura-prune-state` and `zakura-rollback-state`
  binaries, including from the Docker image. Use `zakurad prune-state` and
  `zakurad rollback-state`, which take the same arguments but start from the
  loaded `zakura.toml` instead of the default state configuration; pass
  `--cache-dir` to choose the state directory explicitly
  ([#1997](https://github.com/zakura-core/zakura/pull/1997)).
