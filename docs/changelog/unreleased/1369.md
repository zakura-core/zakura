## Security

- Native legacy block and transaction requests now try the next peer
  alongside one that goes 3 seconds without sending anything or runs past
  8 seconds, so a silent or stalling peer can no longer use up a download's
  deadline, while a slow peer can still answer. A request cancelled while
  waiting for its turn no longer delays later requests
  ([#1369](https://github.com/zakura-core/zakura/pull/1369)).
