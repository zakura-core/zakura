## Added

- Rows with a cadence declare the sender's interval, and `Stream::validate_layout`
  proves that a conformant sender never empties the receiver's bucket. On streams
  with a message table, readers charge only cadence rows, disconnect a peer that
  empties a bucket, and run a service's response precheck before reading the
  payload ([#1139](https://github.com/zakura-core/zakura/pull/1139)).

## Changed

- `Cadence` gains `send_interval`, and `ZakuraHandlerError` gains
  `CadenceExhausted` ([#1139](https://github.com/zakura-core/zakura/pull/1139)).

## Fixed

- Legacy request/response readers enforce each request's remaining response
  budget before allocating payloads. Persistent readers with message tables
  wait for the service's precheck choice before reading frames
  ([#1139](https://github.com/zakura-core/zakura/pull/1139)).
