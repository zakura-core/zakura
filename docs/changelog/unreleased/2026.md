## Changed

- A partial batch in the shielded proof and signature verifiers no longer waits up to
  100 ms for more items when no other transaction is expected in that time. It flushes
  5 ms after its transaction's items stop. Under steady load, batches still wait for more
  transactions, so CPU per proof does not grow
  ([#2026](https://github.com/zakura-core/zakura/pull/2026)).
