## Fixed

- With BPv1 enabled, a node seeds a block it solved even when a peer's metadata for that block arrived first, and reports no BPv1 publication when it could not publish the block ([#2763](https://github.com/zakura-core/zakura/pull/2763)).
- With BPv1 enabled, a block-body claim no longer outlives the block that held it when two BPv1 updates race, so block sync no longer skips that block until the claim expires ([#2763](https://github.com/zakura-core/zakura/pull/2763)).
