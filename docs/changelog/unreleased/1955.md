## Changed

- Block announcements are bounded to the latest work: each peer-to-peer protocol keeps at
  most the latest committed tip and the latest locally mined block waiting for a peer, so a
  node that committed blocks with no peers connected announces the current tip to the first
  peer instead of a backlog of buried blocks
  ([#1955](https://github.com/zakura-core/zakura/pull/1955)).

## Fixed

- A node with only Zakura peers announces its tip and its own mined block to the first
  peer that connects, and a block announcement to Zakura peers that reached nobody is
  retried instead of being recorded as sent
  ([#1955](https://github.com/zakura-core/zakura/pull/1955)).
