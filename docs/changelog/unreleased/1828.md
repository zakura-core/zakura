## Added

- Added optional, explicitly activated Regtest support for post-quantum transparent
  P2SH spends using redeem-script version 1 (SLH-DSA-SHA2-128f) or version 2
  (SLH-DSA-SHA2-192s), including mixed-input transactions, RPC admission,
  mempool policy, and mining
  ([#1828](https://github.com/zakura-core/zakura/pull/1828)).
