## Security

- Authenticate downloaded coinbase heights against the header's transaction Merkle root and, for
  V5+ coinbases, the expiry height, before sync or gossip height policies drop a block.
  The check needs no chain state, so it covers blocks whose parent has not arrived yet.
  Exclude rejected suppliers before retrying the hash on TCP or v2.
  Bound retries without restarting unrelated downloads
  ([#1036](https://github.com/zakura-core/zakura/pull/1036)).
