## Changed

- With BPv1 enabled, a block whose coinbase holds a miner mesh output names its proposer by the output's gateway ID, so `HeaderMeta` leaves out the 32-byte proposer node ID. BPv1 accepts seeds from connections whose node ID starts with that gateway ID. A node whose template names another node's gateway sends its blocks through existing relay ([#2751](https://github.com/zakura-core/zakura/pull/2751)).
