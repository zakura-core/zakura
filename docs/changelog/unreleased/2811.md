## Fixed

- A transaction download now goes to, or waits up to two seconds for, the peer whose announcement it came from, even before that announcement is recorded, instead of a random peer that does not have it. Transactions a zcashd sidecar wallet announces are no longer lost this way ([#2811](https://github.com/zakura-core/zakura/pull/2811)).

- While syncing, a transaction download can still fall back to a ready peer after two seconds even if a block request is waiting for an archive peer ([#2811](https://github.com/zakura-core/zakura/pull/2811)).
