# RocksDB sources compiled with -O3; scripts/rocksdb/cxx.sh builds every other
# RocksDB source in librocksdb-sys with -Os.
#
# Derived from a callgrind profile of a RocksDB benchmark that uses zakura-state's
# options and access patterns: block-style write batches with merges and range
# deletes, flushes and compactions, point reads that hit and miss, snapshot reads,
# merge resolution, seeks and full scans. A source is listed if it executed at
# least 1M instructions (inline functions credited to every file that defines
# them), plus the flush, compaction and WAL sources.
#
# Paths are relative to the rocksdb/ directory of librocksdb-sys.
# scripts/rocksdb/check_hot_sources.py fails when an entry no longer exists.
