## Removed

- Removed unused public APIs: `zakura-chain`'s `transaction::Memo`,
  `sprout::NullifierSeed`, `parallel::commitment_aux_verify::HeaderWitness`,
  `parallel::commitment_aux_verify::normalize_unauthenticated_commitment_fields`,
  and the `confirmed_roots`, `confirmed_hashes`, `confirmed_hash` and
  `header_witness` accessors on `VerifiedHeaderCommitmentRoots`;
  `zakura-consensus`'s `primitives::halo2::Halo2Error`; and
  `zakura-network`'s `PendingUpgrade` and `PendingUpgradeRegistry`
  ([#2403](https://github.com/zakura-core/zakura/pull/2403)).

## Changed

- `zakura-chain`'s `fmt::TypeNameToDebug` is now available only with the
  `proptest-impl` feature
  ([#2403](https://github.com/zakura-core/zakura/pull/2403)).
