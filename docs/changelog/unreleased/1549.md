## Added

- `[network.zakura] trace_tables` selects which CSV trace tables the node
  writes to `trace_dir`. It defaults to every table, and an unknown table name
  is a config error. `trace_enabled = false` stops every table without
  removing the other trace settings
  ([#1549](https://github.com/zakura-core/zakura/pull/1549)).
- A `mining` trace table (`mining.csv`) records each `getblocktemplate`
  response and each `submitblock` or `submitsolution` outcome, including the
  rejection reason ([#1549](https://github.com/zakura-core/zakura/pull/1549)).
