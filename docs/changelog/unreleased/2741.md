## Fixed

- The Docker image now starts as a non-root user (for example with
  `--user 10001:10001`, `--cap-drop=ALL` or `--read-only`). The entrypoint
  changes data directory ownership only when it runs as root; otherwise each
  configured directory must already be writable by that user or its group
  ([#2741](https://github.com/zakura-core/zakura/pull/2741)).
