## Changed

- Reuse saved block-header hashes across validation and legacy block checksum
  lookups. Editing a header clears its saved hash before its fields change
  ([#2561](https://github.com/zakura-core/zakura/pull/2561)).

- Rust callers construct block headers with `Header::new(HeaderData { ... })`.
  Headers implement `Clone` rather than `Copy`; their serialized formats are unchanged
  ([#2561](https://github.com/zakura-core/zakura/pull/2561)).
