## Changed

- The header chain now retains 138 headers of difficulty context below the
  finalized height instead of 112, ready for NU7.1's 128-block averaging
  window. On the `dual` and `zakura` P2P stacks, which attach the header
  chain, startup migrates its database to disk format 6 and backfills the
  extra rows from full state. Older releases refuse a format 6 header-chain
  database. Before downgrading, run `zakurad rollback-state`, which clears the
  header-chain tables so the older release rebuilds them
  ([#2777](https://github.com/zakura-core/zakura/pull/2777)).
