## Security

- Reject invalid native message headers before reading or allocating their
  payloads, validate Block message tags before decoding, and bound nested block
  collection allocations by the payload bytes actually available. Distinguish
  local connection closure from protocol rejection. Retain original response
  authorization through local work changes and validate ordered bodies, actual
  byte limits, and exact endings before releasing protocol slots. Keep requests
  progressing when a preferred peer cannot serve the next missing height
  ([#971](https://github.com/zakura-core/zakura/pull/971)).
