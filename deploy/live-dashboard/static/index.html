DATA & DEFINITIONS

One node. Real observations.

This is an independent, pruned Zakura node on Zcash mainnet. Chain data is polled every 5 seconds, metrics every 15 seconds, and peers and host counters every 30 seconds. Charts retain 24 hours. The selected period controls event counts, cumulative event charts, and recent blocks. Blocks use miner timestamps and are limited to cached, available history.

TPS
Transactions in up to 30 linked block intervals divided by the miner timestamp difference. The oldest boundary block is excluded. Total includes coinbase. Excluding coinbase subtracts one transaction per block. This is not a benchmark or an estimate of network capacity.
Pipeline activity
Event totals sum recorded increases during complete sampling intervals inside the selected period. Cumulative charts show those totals rising over time. Missing data, node restarts, and partial boundary intervals are excluded. Coverage starts when count collection was enabled. Stages count independent events, not one cohort of transactions. TPS and byte throughput stay as rates. Queues, connections, CPU, memory, and latency keep their current units.
Processing timings
Stage charts show sampled rolling p50 and p95 summaries over the selected period. Each chart has its own duration scale. These are not individual block timings. Stages can overlap or run in parallel, so they cannot be added together. Missing observations remain gaps.
Networking
Legacy wire bytes, host interface bytes, and native block payload bytes have different scopes. Peer addresses are omitted. Native QUIC wire bytes, per-peer traffic, loss, and retransmission statistics need additional node instrumentation.
Freshness & finality
Unavailable sources are marked stale. Gaps in observations remain gaps. Finalized height means Zakura’s storage boundary, not absolute proof-of-work finality. Header height does not establish validity. The dashboard continues running while this node restarts.
