## Changed

- `network.unconditional_peers` now keeps one inbound connection slot for each
  entry that Zakura dials. A listed peer can connect while other peers fill
  every public inbound slot, so two full nodes that list each other can always
  connect. The slots come out of the inbound connection limit, so a node has
  one fewer public inbound slot for each dialed entry. A CIDR range of several
  addresses keeps no slot
  ([#2402](https://github.com/zakura-core/zakura/pull/2402)).
