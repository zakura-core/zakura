## Fixed

- Keep ordered response writes independent of blocked application reads and
  cancel paired writes promptly when a peer closes either member. Leave
  connection receive credit for other services when one stream stalls
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Enforce service message allowlists before reading payloads on request/response
  streams as well as ordered streams
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Reject ineligible ordered-stream openers and duplicate offers for active or
  retiring remote sessions before reserving service capacity
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Keep cancellation and expiry responsive during slow stream setup, and defer
  retries briefly after an incomplete pair expires so other sessions can open
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Let paired-session reopening retry while old workers finish or abandoned
  setup remains pending, preserving the connection and its other services
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Keep useful sessions connected when an unneeded negotiated service would
  otherwise make them exceed the connection's stream limit
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
- Preserve native block-download cooldowns and repeated-stall disconnects when
  a service session ends after a peer close or write timeout with unanswered
  requests. Process buffered responses before charging a stall, and keep local
  cancellation and local body backpressure neutral
  ([#943](https://github.com/zakura-core/zakura/pull/943)).

- Release service capacity when every application stream handle is dropped,
  after draining each member's queued writes. Keep retained handles and queued
  writes alive when traffic arrives after an application receiver is dropped
  ([#943](https://github.com/zakura-core/zakura/pull/943)).

## Changed

- Retire only the affected native P2P service session when a persistent stream
  write times out, preserving unrelated services on the connection
  ([#943](https://github.com/zakura-core/zakura/pull/943)).
