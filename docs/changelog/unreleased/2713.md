## Added

- Added the `[memory]` section, which sizes v2 P2P from one node-wide memory
  budget. `budget = "auto"`, the default, reads the tightest of host RAM and
  the cgroup limit. On the `zakura` and `dual` stacks, startup logs the
  memory plan, and on a host below the minimum the chain needs it warns
  once and lists every term
  ([#2713](https://github.com/zakura-core/zakura/pull/2713)).

## Changed

- An idle or still-handshaking v2 peer no longer holds worst-case QUIC
  windows. Memory now decides the connection count: `max_connections` is
  optional and is 256 when unset. On the v2 stack, the default
  `[state] read_result_byte_limit` follows read concurrency instead of the
  peer count
  ([#2713](https://github.com/zakura-core/zakura/pull/2713)).

## Deprecated

- `[network.zakura] peer_memory_budget_bytes` is ignored, and `[memory]
  budget` replaces it. Configs that set it still load, and startup warns
  ([#2713](https://github.com/zakura-core/zakura/pull/2713)).
