## Changed

- The mempool no longer bans peers that relay invalid transactions. Many
  transaction verification failures depend on the node's own view of the chain,
  such as lock times and coinbase maturity checked against a lagging tip, so
  bans cut off honest peers permanently. Instead, the mempool ignores that IP
  address's transaction advertisements for 10 minutes, doubling for repeated
  failures up to 2 hours. Block verification failures still ban peers
  ([#960](https://github.com/zakura-core/zakura/pull/960)).
