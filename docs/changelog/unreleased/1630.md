This PR splits the block-sync peer routine into a pure `PeerState` and a
`PeerIO`, routes the fill pass through queue-owned funding, makes the receipt
path synchronous behind a pre-acquired sequencer permit, and adds machine tests
for them. Internal traces and one metric gain funding and filtering detail.
Request issuance, response handling, deadlines, fault attribution, and
settlement keep their behavior, so the PR has no operator- or
crate-consumer-visible effect.
