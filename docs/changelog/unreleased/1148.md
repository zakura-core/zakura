## Changed

- From NU7 activation, the block subsidy and the funding stream values are split
  exactly over each group of three 25-second blocks, so every group pays exactly what
  one 75-second block paid to the subsidy, to each funding stream, and to the miner.
  Plain per-block floors paid the ZCG and lockbox streams a few zatoshi less, and the
  miner more, for every three blocks. No public network sets an NU7 height yet, so
  behavior does not change today
  ([#1148](https://github.com/zakura-core/zakura/pull/1148)).
