## Security

- Native legacy requests now move on from a peer that has not started
  answering within 3 seconds, unless it is the last peer tried, so a silent
  peer can no longer use up a block, transaction, or tip request's deadline.
  A request cancelled while waiting for its turn no longer delays later
  requests ([#1369](https://github.com/zakura-core/zakura/pull/1369)).
