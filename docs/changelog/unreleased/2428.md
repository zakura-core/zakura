## Changed

- The connection warm-up (`network.tcp_warmup`, off by default) now stops at a
  512 KiB ping by default instead of the largest ping a peer accepts. It sends
  each peer about 1.4 MB of padding instead of 5.7 MB, and a block of the
  largest size then takes two round trips instead of one. Set
  `max_chunk_bytes = 2097144` to keep the previous behavior
  ([#2428](https://github.com/zakura-core/zakura/pull/2428)).
