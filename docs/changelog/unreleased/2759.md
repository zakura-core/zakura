## Added

- A pool can name its public relay node as its miner mesh gateway with
  `mining.miner_mesh_gateways`, so its blocks point other pools at the relay
  rather than at a private template node, and a relay with `miner_mesh` set
  keeps places for other pools' gateways. The relay lists its template nodes
  in `mining.miner_mesh_template_nodes` to keep a connection place for each,
  so they can always connect in, and `getminermeshinfo` marks them with
  `template_node`
  ([#2759](https://github.com/zakura-core/zakura/pull/2759)).
