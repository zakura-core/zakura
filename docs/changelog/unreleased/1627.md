This PR restructures the header-sync peer routine's internals. The
publisher's, subscriber's, and session reader's policy moves into pure state
types under their existing locks, and publisher jobs gain exact keys.
The publisher's slots, capacity signals, and frames stay in its runtime owner,
which names them to the pure state by exact identity.
The publication ledger returns facts, and its runtime owner emits the same
metrics, logs, and transition events from them.
The simulator gains a `header/publisher-policy` machine harness over the existing
publisher model, which bumps the simulator's trace format to 24.
A page whose subscription ended now drops when the subscription ends, not when
the task takes its terminal outcome, so its queue slot frees sooner.
The header sync budget's output share becomes one subscription's byte credit
plus one largest page, and `v9::serving_limits` builds the publisher's serving
limits from a per-peer output value. Production keeps the 64 MiB default.
Wire formats, configuration, and metrics do not change, so it has no operator-
or crate-consumer-visible effect. Only the simulator's trace format changes.
