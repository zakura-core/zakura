## Fixed

- The internal miner replaces an empty mining template when a template containing transactions
  arrives. A node answers a long poll from an older tip with a template that carries no mempool
  transactions, so that a miner can start on the new parent without waiting for the mempool. The
  update that then brings those transactions reports that the work already issued is still valid.
  The miner previously kept that empty work. It now gives it up when an update carries
  transactions, while preserving valid work that already contains transactions
  ([#2203](https://github.com/zakura-core/zakura/pull/2203)).
