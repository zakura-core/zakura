## Security

- Bounded the work, memory and in-flight requests a peer can demand from
  GetBlocks serving on native block-sync version 3, advertising at most 2,816
  in-flight requests per peer by default. Peers without version 3 keep version
  2 behavior. Block-sync configs with more than 3,633 inbound plus outbound
  peer slots are now rejected at startup
  ([#1174](https://github.com/zakura-core/zakura/pull/1174)).
