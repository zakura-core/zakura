## Changed

- Block verification no longer parses a transaction a second time when its
  shielded proofs and signatures were already verified, as they are for a
  transaction the node admitted to its mempool. This removes most of the block
  verifier's CPU for blocks of shielded transactions
  ([#2420](https://github.com/zakura-core/zakura/pull/2420)).
- `SigHasher::new` and `Transaction::sighasher` in `zakura-chain` no longer
  read a v4 or later transaction with `librustzcash`, so they no longer fail
  for one it cannot parse. They still check the consensus branch ID
  ([#2420](https://github.com/zakura-core/zakura/pull/2420)).

## Removed

- Removed `SigHasher::sapling_bundle`, `SigHasher::orchard_bundle` and
  `SigHasher::ironwood_bundle` from `zakura-chain`. The new
  `Transaction::shielded_bundles` returns the same bundles
  ([#2420](https://github.com/zakura-core/zakura/pull/2420)).
