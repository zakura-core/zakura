## Fixed

- Legacy sync now checks that a downloaded block's parent can be built on, or
  is still downloading and has passed the same check, before verifying it, so
  blocks that can't connect to the chain are dropped right away instead of
  waiting in the verifier. A block whose parent is still on its way is
  downloaded again once that parent verifies
  ([#1929](https://github.com/zakura-core/zakura/pull/1929)).
