## Changed

- Verifying a new block hashes transaction IDs on several threads when there are
  at least 64 transactions and multiple CPU workers, and hashes large transaction
  Merkle tree levels of at least 512 hashes in parallel. Large-block hashing runs
  on blocking threads so waiting for CPU workers does not hold async workers;
  other Merkle-root callers keep serial construction
  ([#2005](https://github.com/zakura-core/zakura/pull/2005)).
