## Fixed

- A block mined by this node is announced to peers once, as a mined block,
  even when its `submitblock` call takes more than about 1 ms to finish after
  the block commits, or when it commits on top of a block relayed moments
  earlier. A block submitted to this node that was also received from a peer
  is still announced
  ([#2091](https://github.com/zakura-core/zakura/pull/2091)).
