## Changed

- A v2 node now uses its Zakura bootstrap peers only to find its first peers. It dials them while it has peers on fewer than two other hosts, and once peers on four other hosts, inbound or outbound, have stayed connected for a minute it closes the connections its discovery opened to them. A bootstrap peer pinned in `network.unconditional_peers`, reached through a legacy-to-v2 upgrade, or connected to this node on its own initiative stays connected. The bootstrap peers' inbound slots no longer fill once the v2 network outgrows them. A small network whose nodes are all bootstrap peers keeps them connected as before ([#2786](https://github.com/zakura-core/zakura/pull/2786)).
