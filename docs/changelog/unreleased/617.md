## Added

- Added header-time authentication for peer-supplied verified-commitment-tree
  metadata: during fast sync each supplied root is now checked against the
  one-header-later commitment that proves it as soon as that header arrives,
  instead of waiting for its block body to reach the committer, so an invalid
  root is evicted and its replacement requested while the committer is still far
  below it
  ([#617](https://github.com/zakura-core/zakura/pull/617)).

## Removed

- Removed the height-keyed header-root authentication lane that the fork-aware header chain
  replaces: the `AuthenticateHeaderRoots` request, its durable ascending frontier, and the
  `header_root_auth_frontier` column family. The frontier was still being folded and rewritten
  on every block commit even though nothing read it. A database written by an earlier version
  keeps the column family but has its row cleared on upgrade; new databases never create it
  ([#617](https://github.com/zakura-core/zakura/pull/617)).
