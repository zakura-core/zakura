## Changed

- QUIC connection traces can show a null peer ID until the control handshake
  identifies the peer. In the Rust transport API, `Conn::remote_id()` and
  `ConnSample::remote_id` now return or hold `Option<NodeId>`. Callers that
  need the authenticated key before this point can use `Conn::remote_key()`
  ([#2653](https://github.com/zakura-core/zakura/pull/2653)).
