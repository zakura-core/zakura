## Added

- Added the experimental `network.experimental_early_block_relay` option, off
  by default. When both legacy peers set service bit 25, the bit Zebra's
  Ándale release uses, Zakura relays a fully verified NU5 or later tip block
  before its contextual commit finishes, and does not score a negotiated peer
  for a block that fails after its header and commitments check out
  ([#773](https://github.com/zakura-core/zakura/pull/773)).
