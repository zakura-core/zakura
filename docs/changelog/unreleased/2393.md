## Added

- `network.unconditional_peers` entries can now be DNS names with a port, such
  as `"peer.example.com:8233"`. Zakura looks the name up again at the start of
  every dial, so it follows a peer whose name moves to a new address. The
  addresses the name resolved to are exempt from scoring and bans, and can use
  the inbound slots that listed peers share. A name adds one outbound and one
  inbound slot, however many addresses it resolves to. At startup, Zakura waits
  up to six seconds for the names' first lookups, so its other dials leave the
  names' addresses the room they need. It does not
  look a name up while that peer is connected. When a lookup fails, Zakura
  dials the addresses of the last lookup that worked. Whoever controls a listed
  name chooses addresses that Zakura trusts, so only list names whose DNS you
  control ([#2393](https://github.com/zakura-core/zakura/pull/2393)).
