## Added

- ZIP 234 "Network Sustainability Mechanism: Issuance Smoothing", behind two
  off-by-default build features that match the issuance options on the NU7 ballot.
  `zip234` replaces halvings with a smoothed curve. `zip234-halvings` keeps the
  halving schedule and adds a bonus from the same curve. Both options use the money
  reserve and start at the configured deployment height. Both options scale their
  per-block reissuance fraction when ZIP 218 enables 25-second blocks
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
- `testnet_parameters.zip234_deployment` accepts `"nu7"`, the default, or a block
  height. A configured height below NU7 activation is rejected
  ([#859](https://github.com/zakura-core/zakura/pull/859)).

## Changed

- `block_subsidy` takes the money reserve after the parent block, which ZIP 234
  needs. Callers that cannot reach a ZIP 234 height pass `None`, and get a
  `MissingMoneyReserve` error rather than a wrong subsidy if that ever changes
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
- `ReadRequest::BlockInfo` searches every non-finalized chain instead of only the
  best chain, so a block verifier can look up a parent on a fork. Height queries
  still resolve on the best chain first
  ([#859](https://github.com/zakura-core/zakura/pull/859)).
