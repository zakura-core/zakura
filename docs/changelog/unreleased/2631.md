This PR only changes how long the node keeps an internal record of a block it
mined, within the unreleased behavior that
[#2605](https://github.com/zakura-core/zakura/pull/2605) already describes.
The one visible difference is in that PR's unreleased
`sync.block.announcement_claim` counter, where a rival body that arrives after
its deadline can be counted as `expired` instead of `voided`.
