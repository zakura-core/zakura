## Changed

- Omit transparent address and spender indexes in fresh pruned checkpoint-sync
  databases while retaining validation and mining support. Existing indexed
  databases keep their indexes, and index-free databases retain their behavior
  across restarts and use separate database and backup directories
  ([#1366](https://github.com/zakura-core/zakura/pull/1366)).
- Return an explicit unavailable error for address balance, UTXO, transaction
  history, and transparent spender queries when their indexes are omitted
  ([#1366](https://github.com/zakura-core/zakura/pull/1366)).
