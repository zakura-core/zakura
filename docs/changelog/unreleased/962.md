## Added

- Added opt-in spentness construction with durable restart recovery, state availability gates, and an offline progress audit. The mode defaults to `off` and requires a reviewed artifact commitment. Construction must end before the block that seeds the NU7 NSM balance ([#962](https://github.com/zakura-core/zakura/pull/962)).

## Changed

- Bump `zakura-state` and `zakura-consensus` to 9.0.0 for breaking public API changes.

- Retry pre-state artifact acquisition across peer cohorts for up to one hour.
  Auto mode then falls back to ordinary sync; Require mode reports failure.

- Moved state to database format 30 to isolate incomplete spentness construction from older binaries. The upgrade reuses ordinary format-29 state ([#962](https://github.com/zakura-core/zakura/pull/962)).

- `getblockchaininfo` omits `chainSupply` and `valuePools` during spentness construction, and reports the real tip instead of genesis ([#962](https://github.com/zakura-core/zakura/pull/962)).

## Fixed

- Include retained spentness frontiers and their registry in release-import recovery.
