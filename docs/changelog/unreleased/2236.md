## Changed

- Orchard and Ironwood proving and verifying now run on the native sensei/udon
  backend; the legacy halo2 circuit stack leaves the build entirely
  ([#2236](https://github.com/zakura-core/zakura/pull/2236)).
- Extended `sync.parallel_cpu_threads` to also size the native backend's
  private worker pool for Orchard proving and proof verification, matching
  the rayon pool it already configured
  ([#2236](https://github.com/zakura-core/zakura/pull/2236)).
- Provisioned reusable verification scratch for a typical full Orchard batch
  in the background at startup, after the verifying keys are built, reducing
  first-batch initialization and allocation costs
  ([#2236](https://github.com/zakura-core/zakura/pull/2236)).
