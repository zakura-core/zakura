## Added

- Added header-time authentication for peer-supplied verified-commitment-tree metadata.
  During fast sync, Zakura checks each supplied root against its successor commitment.
  Zakura rejects failures that identify one delivery.
  Zakura disputes ambiguous failures and requests replacement metadata.
  The block committer independently verifies every supplied root before persistence
  ([#617](https://github.com/zakura-core/zakura/pull/617)).

## Removed

- Removed the height-keyed header-root authentication lane.
  Zakura no longer exposes the `AuthenticateHeaderRoots` request.
  Zakura no longer stores its durable frontier or the `header_root_auth_frontier` column family.
  The database upgrade clears the retired frontier row.
  New databases do not create the retired column family
  ([#617](https://github.com/zakura-core/zakura/pull/617)).
