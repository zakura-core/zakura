## Security

- Bound native GetBlocks serving to one response per authenticated peer and 64
  per node, retaining capacity through storage, queued results, and writes
  across reconnects. Use paired block-sync streams so serving waits pause
  request intake while downloads continue, reject malformed request headers
  before allocation, and retain complete bounded response prefixes under
  congestion. Preserve no-progress cooldowns and repeated-stall disconnects
  across remote resets and data-write timeouts. The previous native block-sync version is not selected;
  other services and legacy fallback remain available
  ([#945](https://github.com/zakura-core/zakura/pull/945)).
