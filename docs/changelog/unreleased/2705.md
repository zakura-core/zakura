## Added

- Added the `end_of_support.halt` setting. With `halt = false`, a node that
  does not mine keeps running past the last height its release supports and
  warns instead of halting. It warns again while a network upgrade after its
  support window is ahead, and once it has run through one. Mining nodes keep
  the halt. See `docs/end-of-support.md`
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).
- Added the `end_of_support.blocks_until_next_upgrade` and
  `end_of_support.upgrade_activated_unsupported` metrics, and alerts for a
  release that runs unsupported
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).

## Changed

- The `end_of_support.enforced` metric is now `1` only when the node halts at
  the end of its release's support
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).
- The `ZakuraEndOfServiceImminent` alert now fires only for a node that halts,
  and `ZakuraEndOfServiceApproaching` stops once the tip is past the last
  supported height, where the alerts for an unsupported release take over
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).

## Fixed

- Fixed the end-of-service alert and dashboard thresholds, which still assumed
  75-second blocks and so fired at one day and eight hours instead of three
  days and one day
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).
- Fixed the first end-of-support check being delayed by an hour when the state
  had no chain tip ten seconds after startup
  ([#2705](https://github.com/zakura-core/zakura/pull/2705)).
