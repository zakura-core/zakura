## Changed

- `getblocktemplate` now answers a long poll on a new tip with the full
  template when the mempool already holds transactions for that tip, instead
  of always answering with a coinbase-only template first. It still answers
  coinbase-only when the mempool is empty, has not processed the new block
  within 10 ms, the miner address is shielded and its coinbase was built in
  advance, or three other long polls are already building a full template for
  a new tip ([#2343](https://github.com/zakura-core/zakura/pull/2343)).
- `getblocktemplate` builds a template for a miner paid to a transparent
  address without handing the build to another thread, which removes a wait
  that was longer than the build itself when a new block arrives. Templates
  that need a proof for a shielded miner reward are built as before, and
  templates are still built one at a time
  ([#2343](https://github.com/zakura-core/zakura/pull/2343)).
