## Fixed

- The internal miner no longer mines empty blocks while the mempool holds transactions. A node
  answers a long poll from an older tip with a template that carries no mempool transactions, so
  that a miner can start on the new parent without waiting for the mempool, and the update that
  then brings those transactions reports that the work already issued is still valid. The miner
  kept that work, so on a chain it mines by itself every block came out empty. It now gives up
  work on an empty block when an update carries transactions, and only then
  ([#2203](https://github.com/zakura-core/zakura/pull/2203)).
