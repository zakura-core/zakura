## Added

- Added v7 coinbase transactions to `getblocktemplate` from NU7.1, falling
  back to the earlier coinbase format at a ZIP 271 lockbox disbursement
  height. Like NU7.1 validation, this only applies to test builds on Regtest
  or configured Testnets that set an NU7.1 height
  ([#248103](https://github.com/zakura-core/zakura/pull/248103)).
- Added the `valuePoolDeltas` and `coinbase` fields to verbose
  `getrawtransaction` and `getblock` transaction output for v7 transactions,
  which only those test networks contain. A v7 coinbase transaction has no
  coinbase input, so its verbose `vin` is empty, and pool and explorer
  software that detects a coinbase by `vin[0].coinbase` misclassifies it.
  Detect a v7 coinbase by its `coinbase` object instead, which states the
  block height in `blockHeight`, the issuance in `blockSubsidy` and
  `lockboxValue`, and the miner's data in `coinbaseData` and, when the miner
  answers a poll, `minerPoll`, which is omitted otherwise
  ([#248103](https://github.com/zakura-core/zakura/pull/248103)).
