## Changed

- BPv1 now sends `HeaderMeta` on the data stream, ahead of the block's parts and `Have`s. A peer that sends a block's parts or `Have`s before its `HeaderMeta` crossed the connection is now disconnected. BPv1 moves to stream version 2 under capability bit 13 and retires bit 12, so a node on this release runs no BPv1 session with a `v1.9.0` BPv1 peer but keeps the connection ([#2810](https://github.com/zakura-core/zakura/pull/2810)).
