## Changed

- The sync lookahead limits now scale by exactly `75 / spacing`, rounded up,
  so they keep their time window at NU7.1's 20 second spacing instead of
  shrinking by a fifth. NU7.1 has no Mainnet or Testnet activation height
  ([#2781](https://github.com/zakura-core/zakura/pull/2781)).

## Fixed

- Near the final checkpoint, the state now keeps queued checkpoint outputs
  available for the syncer's whole scaled pipeline: 9,000 blocks by default on
  Mainnet and Testnet instead of 3,000. Before, a block just past the final
  checkpoint could time out waiting for an output from a checkpoint block that
  was still being written
  ([#2781](https://github.com/zakura-core/zakura/pull/2781)).
