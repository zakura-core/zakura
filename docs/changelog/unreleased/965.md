## Changed

- The node writes all structured trace tables as CSV with absolute UTC timestamps and bounded rotation. `ZAKURA_TRACE_FILE_BYTES` and `ZAKURA_TRACE_FILE_SEGMENTS` set the segment size and count; a count of zero hands rotation to an external tool. Trace readers, the regtest oracle, and diagnostic archives support plain and gzip-compressed CSV segments ([#965](https://github.com/zakura-core/zakura/pull/965)).

- Validation captures now require sealed writer evidence and process-scoped commit matching. Trace readers reject malformed or incomplete evidence and bound imported data.
