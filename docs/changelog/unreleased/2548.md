## Added

- `[network.block_hedge]`, off by default: when a block a legacy peer announced hasn't
  arrived `delay` (default 50 ms) after it was requested, the node also requests it from one
  other idle peer that announced it, picked by the fastest heartbeat ping, and uses whichever
  copy arrives first. The legacy peer trace records these downloads with the route `hedge`
  ([#2548](https://github.com/zakura-core/zakura/pull/2548)).
