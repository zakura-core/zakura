## Added

- With `network.zakura.trace_dir` set, legacy peer connections write
  `legacy_gossip.jsonl`: each block announcement received from or sent to a
  peer, each block a peer asked for, and each block sent to it or found
  missing. The start time in a trace row's `process_trace_id` is now the moment
  its `ts` counts from, so adding the two gives the row's wall-clock time
  ([#2446](https://github.com/zakura-core/zakura/pull/2446)).
- Added `network.zakura.trace_peer_names`, a list of `name = "ip address"`.
  A legacy peer at a listed address is recorded under its name in
  `legacy_gossip.jsonl`; trace rows still never hold a peer's address
  ([#2446](https://github.com/zakura-core/zakura/pull/2446)).
