## Added

- Added a `trace_epoch_us` field to every JSONL trace row. It counts
  microseconds from one monotonic epoch per process, so rows from different
  trace tables of one node can be ordered on one clock. The existing `ts` field
  keeps its meaning
  ([#1975](https://github.com/zakura-core/zakura/pull/1975)).
- Added a `trace_rows_unconfirmed` field to every JSONL trace row. It counts the
  rows the tracer refused or could not confirm as written, so an increase shows
  that the trace may be incomplete. It is not an exact count of lost rows
  ([#1975](https://github.com/zakura-core/zakura/pull/1975)).
