## Fixed

- Miners get a full block template sooner after a chain reorganization. A
  `getblocktemplate` long poll that holds a template without transactions now
  returns as soon as the mempool changes, instead of waiting up to 5 seconds
  for the next mempool poll. A new tip no longer waits for the long poll's
  empty-block coinbase precomputation
  ([#2259](https://github.com/zakura-core/zakura/pull/2259)).
