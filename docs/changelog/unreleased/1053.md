## Added

- Add parent-dependent NU7 reissuance and negative-deficit rejection. Both activate by height alone, in every build. Block proposals reject a parent that has not committed instead of waiting for it. Configured testnets and Regtest can set the reissuance start with `zip234_start_height`. Production activation remains pending policy and network parameters. ([#1053](https://github.com/zakura-core/zakura/pull/1053)).

## Changed

- The format 29 migration refuses a database whose tip is at or above the reissuance start, because older versions committed those blocks without reissuance. Delete the database and sync again. ([#1053](https://github.com/zakura-core/zakura/pull/1053)).
