## Added

- `[network.block_source_score]`, off by default: when several idle legacy peers announced a
  block, the node asks the one expected to answer sooner, from its recent ping, transaction and
  small block answer times, instead of the less loaded one. The legacy peer trace records each
  choice (`candidates`, `score_ms`, `best_score_ms`)
  ([#2558](https://github.com/zakura-core/zakura/pull/2558)).
