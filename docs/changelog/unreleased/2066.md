## Fixed

- Discovery now vouches in peer samples only for record addresses this node
  authenticated. A peer's own `Hello` confirms only its connection's remote
  address, and a dial confirms only the address it reached, so the node no
  longer re-gossips a peer's record on the strength of victim addresses the
  peer lists
  ([#2066](https://github.com/zakura-core/zakura/pull/2066)).
