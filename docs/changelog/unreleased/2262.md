## Changed

- Miners get the full block template sooner after a new tip. When a
  `getblocktemplate` long poll sees a new tip, it still returns the template
  without transactions at once, and the node also starts building the full
  template for that tip. Long polls that ask for the same work then share
  that one template instead of each building their own
  ([#2262](https://github.com/zakura-core/zakura/pull/2262)).
